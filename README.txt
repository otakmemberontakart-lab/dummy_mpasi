Semua file ini BUKAN file biasa yang bisa dibuka lewat aplikasi

Ikuti panduan sesuai perangkat Bunda di bawah ini ya 👇


========================================================
  A. DI PC / LAPTOP (Windows / Mac)
========================================================

1. Download file ZIP yang dikirimkan, simpan di folder mana saja
   (misal folder Download).

2. Extract / Unzip file tersebut:
   - Windows : klik kanan pada file ZIP -> pilih "Extract All"
     -> pilih lokasi -> klik "Extract".
   - Mac     : cukup double-click file ZIP, otomatis akan
     membuat folder baru berisi semua file HTML-nya.

3. Buka folder hasil extract tadi. Bunda akan melihat semua
   file HTML di dalamnya.

4. Double-click salah satu file HTML (misal
   "MPASI_Cegah_Stunting.html") -> otomatis akan terbuka di
   browser (Chrome/Edge/Safari) dan siap dipakai.

5. Ulangi untuk membuka Kit lainnya, atau buka beberapa sekaligus
   di tab browser yang berbeda.

TIPS: Jangan pindahkan file HTML sendirian keluar dari foldernya.
Simpan seluruh folder hasil extract di satu tempat supaya rapi
dan mudah dicari lagi nanti.


========================================================
  B. DI HP ANDROID
========================================================

1. Download file ZIP (dari link/email/WA), biasanya otomatis
   tersimpan di folder "Download".

2. Buka aplikasi "File Manager" / "Files" / "Pengelola File"
   bawaan HP Bunda (bukan aplikasi WhatsApp).

3. Cari file ZIP tadi di folder Download, lalu TAP & TAHAN
   (long-press) file tersebut -> pilih "Extract" / "Unzip" /
   "Ekstrak di Sini".
   - Kalau HP Bunda tidak punya opsi Extract, install dulu
     aplikasi gratis "ZArchiver" dari Play Store, lalu ulangi
     langkah ini.

4. Setelah proses extract selesai, akan muncul folder baru
   berisi semua file HTML.

5. Buka folder tersebut, lalu tap salah satu file HTML.
   Jika muncul pilihan aplikasi, pilih "Chrome" (atau browser
   apa saja yang Bunda punya) -> pilih "Selalu" / "Just Once".

6. Halaman Kit akan terbuka otomatis di Chrome dan siap dipakai
   seperti aplikasi biasa.

TIPS: Kalau Bunda mau akses cepat, buat Bookmark/Shortcut halaman
tersebut di layar utama HP lewat menu titik tiga di Chrome ->
"Tambahkan ke Layar Utama".


========================================================
  C. DI iPHONE / iPAD (iOS)
========================================================

PENTING untuk pengguna iPhone/iPad: sistem iOS memang agak
"rewel" kalau membuka file HTML langsung lewat app Files bawaan
— kadang halaman terbuka tapi fitur interaktifnya (tracker,
kalkulator, quiz, dll) tidak bisa menyimpan data dengan baik.
Supaya semua Kit berjalan MULUS dan datanya TERSIMPAN, ikuti
cara berikut (hanya perlu install 1 aplikasi gratis, sekali saja):

LANGKAH 1 — Install aplikasi "Documents by Readdle"
   Buka App Store -> cari "Documents by Readdle" -> Install
   (aplikasi ini gratis & sangat populer, dipakai jutaan orang).

LANGKAH 2 — Masukkan file ZIP ke aplikasi Documents
   Ada 2 cara, pilih yang paling gampang buat Bunda:
   a) Kalau file ZIP dikirim lewat link/Google Drive:
      buka link tersebut di app "Documents" (ada browser
      bawaan di dalamnya), lalu download filenya di sana.
   b) Kalau file ZIP sudah ada di app "Files" (Files bawaan
      iPhone) atau di WhatsApp/Email:
      tap tombol "Share" / "Bagikan" pada file ZIP tersebut,
      lalu pilih "Save to Files" -> simpan ke Documents, ATAU
      pilih langsung ikon "Documents" jika muncul di menu Share.

LANGKAH 3 — Extract file ZIP di dalam app Documents
   Di dalam app Documents, cari file ZIP yang sudah tersimpan,
   lalu TAP & TAHAN (long-press) -> pilih "Extract" / "Unzip"
   (folder baru akan otomatis terbuat).

LANGKAH 4 — Buka file HTML
   Masuk ke folder hasil extract -> tap file HTML yang mau
   dibuka (misal "Kit 1 - Daily Command Center.html").
   File akan otomatis terbuka di dalam browser bawaan Documents
   dan SEMUA fitur (isi data, simpan tracker, quiz, dll) akan
   berjalan normal dan tersimpan.

LANGKAH 5 — Akses berikutnya
   Untuk pemakaian selanjutnya, Bunda tinggal buka app
   "Documents" -> masuk ke folder tadi -> tap file HTML-nya lagi.
   Tidak perlu extract ulang.

------ CARA CEPAT (kalau cuma mau BACA, tanpa perlu simpan data) ------
Kalau Bunda cuma mau baca Ebook (MPASI_Cegah_Stunting.html) tanpa
perlu fitur simpan data, bisa juga dengan cara lebih singkat:
   1. Simpan file ZIP ke app "Files" bawaan iPhone.
   2. Tap file ZIP -> otomatis ter-extract jadi folder oleh iOS.
   3. Tap file HTML-nya -> pilih "Buka dengan Safari" jika ada
      pilihan tersebut di pojok kanan atas.
Catatan: cara ini KURANG disarankan untuk Kit 1, 2, 3, dan 5
karena kit-kit tersebut punya fitur isi & simpan data (tracker,
food diary, quiz), yang lebih stabil kalau dibuka lewat app
Documents seperti Langkah A di atas.


========================================================
  CATATAN PENTING UNTUK SEMUA PERANGKAT
========================================================

- Data yang Bunda isi di Kit (profil bayi, growth tracker, food
  diary, hasil quiz) tersimpan otomatis di HP/PC yang Bunda
  pakai untuk membuka file tersebut. Jadi selalu buka Kit dari
  perangkat & folder/app yang SAMA supaya data tidak hilang.

- Jangan uninstall app Documents (di iOS) atau hapus folder hasil
  extract, karena data tracker tersimpan di situ.

- Kalau Bunda ganti HP atau install ulang, sebaiknya screenshot
  atau catat data penting (growth tracker, dll) sebelum berganti
  perangkat.

- File ZIP boleh dihapus SETELAH proses extract selesai dan
  Bunda sudah berhasil membuka file HTML-nya. Yang penting
  disimpan adalah folder hasil extract-nya.
